# H-E-B In-Stock Command Center

A field-facing command center for monitoring in-stock performance, prioritizing store and item gaps, tracking cases added, and translating interventions into estimated sales dollars.

## Included

- Executive in-stock overview with 98.5% target tracking
- Store execution table with status and delivery visibility
- Item tracker with status, quantity-added dropdowns, case pricing, and sales-added calculations
- Weekly added-sales analysis
- Delivery and merchandising field schedule
- Search, filters, CSV export, mobile-responsive layout
- Local browser persistence for item status and case additions

## Deploy to Vercel

[![Deploy with Vercel](https://vercel.com/button)](https://vercel.com/new/clone?repository-url=https%3A%2F%2Fgithub.com%2Fdedahlberg%2FHEB-InStock-Command-Center&project-name=heb-instock-command-center&repository-name=HEB-InStock-Command-Center)

The repository includes `vercel.json` and is ready for a static Vercel deployment from the repository root. Use the button above to create the project in the `GO big` Vercel team, then deploy production from `main`.

## Run locally

Open `index.html` in a browser, or serve the folder with any static web server.

## Data

Current store, item, trend, and schedule data in `data.js` is sample operating data intended to make the dashboard functional immediately. Replace or automate these inputs as live H-E-B reporting sources become available.
